运行日志（可观测性）

记录接口请求、工具调用、记忆检索、任务规划、错误与重试。日志上限 300 条，自动保留最新。

记忆与知识库

长期记忆保存跨会话的用户偏好与事实，发送消息时按相关性自动召回并注入上下文（按需检索，不全量灌入）。删除条目即遗忘。
知识库（简易 RAG）：添加内部资料，导入时按约 180 字自动分块索引；提问时用 BM25 打分召回最相关片段（条数可在设置调整）注入上下文作为事实依据，引用带【来源】标注，减少幻觉。

Agent 观测台

渗透工具库

MCP（Model Context Protocol）让 Agent 对接外部工具服务，扩展能力边界。可连接本地 stdio 服务（如 npx @modelcontextprotocol/server-xxx）或 Streamable HTTP 服务（如 Burp Suite 的 MCP 桥接）。仅连接你信任的服务。
添加 MCP 服务
内置渗透测试常用工具，链接均为官方发布页。点击「下载」打开官网获取安装包；「移除」可删除不需要的工具；也可添加自定义工具。
添加自定义工具
渗透技能库（Skills）：沉淀渗透方法论——步骤、经验、踩坑案例，按分类管理。执行渗透任务时按任务语义按需召回相关技能注入上下文（不全量灌入，防止 token 爆炸）；任务结束后可复盘，把新坑新经验沉淀回技能库，形成迭代闭环。技能分「全局库」（多项目共用）与「本项目私有」。
